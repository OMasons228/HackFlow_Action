# HackFlow_Action
Web site platform with accessibility to make forms and registrations to hackthon plus with ability to check our test form with help of organizators and so on!

# HackFlow — платформа отбора участников студенческих хакатонов

MVP: регистрация участников, отборочная воронка (тест + задание с материалом), проверка организатором, автоматическое определение допуска, уведомления.

## Запуск
Сборка не нужна — это один статичный файл `index.html`. Откройте его в браузере или выложите на любой статический хостинг:
- **Netlify Drop:** https://app.netlify.com/drop → перетащить папку с `index.html` → получите публичную ссылку (имя сайта меняется в Site settings).
- **GitHub Pages:** загрузить файлы в репозиторий → Settings → Pages → Deploy from branch `main` → `/ (root)`.

## Тестовые аккаунты
| Роль | Почта | Пароль |
|---|---|---|
| Участник | student@hackflow.ru | student123 |
| Организатор | org@hackflow.ru | org123 |

На странице входа есть кнопки быстрого входа. «Сбросить демо-данные» — в окне «Тестовые аккаунты и инструкция» на главной.

## Проверка основного сценария
1. Участник: «Зарегистрироваться» (или войти как student) → «Мой отбор» → «Тест по основам IT» → ответить на все вопросы → «Завершить тест».
2. Участник: «Видеовизитка» → вставить ссылку (https://...) или файл → «Отправить на проверку». Статус станет «Ожидает проверки».
3. Организатор: «Проверка» → оценить открытый ответ теста и видеовизитку («Принять» / «Отклонить»).
4. Организатор: «Участники» → карточка участника → при необходимости изменить статус вручную → «Выгрузить результаты (CSV)».
5. Участник: кнопка «Уведомления» и обновлённый статус; при допуске в кабинете открывается информация об основном этапе.
6. Организатор: «Испытания» — создание тестов (вопросы с вариантами и открытые), заданий, дедлайнов, порядок стрелками. «Обзор» — воронка и конверсия.

## Реализовано по ТЗ
Регистрация и вход, профиль (ФИО, почта, телефон, Telegram, вуз, направление, курс), привязка к мероприятию, сохранение между сессиями; тест с автопроверкой и открытыми вопросами (ручная проверка), проходной балл; задание с файлом/ссылкой, сроком, временем отправки; 5 статусов с автоматическим расчётом и ручной правкой; закрытая информация основного этапа только для допущенных; уведомления внутри платформы; кабинет организатора с просмотром ответов теста по каждому вопросу (мероприятие, испытания, список с фильтрами, результаты, проверка, выгрузка CSV, аналитика).

Дополнительно: автоматический рейтинг участников (средний результат испытаний), быстрые кнопки «Допустить» / «Отклонить заявку».

## Ограничения MVP
Данные хранятся в localStorage браузера (без сервера), поэтому участник и организатор должны входить в одном браузере. Письма на почту не отправляются. Файлы до 1 МБ сохраняются целиком, для больших — только название.
